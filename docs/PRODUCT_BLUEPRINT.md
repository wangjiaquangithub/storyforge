# StoryForge 产品蓝图

## 愿景

让每一位职业网文作者都能用 AI 流水线把创意变成百万字长篇，同时保持对内容的完全控制。

---

## 当前状态：v1 — 可用闭环

**已交付能力：**

```
创意输入 → Brief → 大纲(Arc分组) → 逐章生成 → Review → 导出
              ↑                      ↓
              └───── 版本追溯 ←──────┘
```

- 68 个已实现功能，137 个测试全绿
- 三栏 Web 工作台 + CLI 命令 + 20+ REST API
- 多 Provider LLM 路由（Anthropic / OpenAI / 本地回退）
- SQLite 持久化 + 乐观并发控制
- 协作者管理 + 编辑审计 + 角色权限控制
- 四种导出格式（Markdown / Text / 起点 / 晋江）
- 内容质量引擎 + A/B 实验预留
- 大纲 Arc 结构分组

**验证方式：**
- API 烟测覆盖黄金路径
- 浏览器端到端验收通过
- CLI 命令全测试

## v2 近期规划（3 个月内）

### 2.1 协作增强

| 功能 | 价值 |
|------|------|
| 角色权限控制 | API 级别按角色限制操作，防止误改 |
| 实时协作编辑 | WebSocket 级实时同步，适合编辑+作者配合 |
| 评论与批注 | 在资产上添加评论，讨论章节修改方向 |

### 2.2 写作体验

| 功能 | 价值 |
|------|------|
| 键盘快捷键 | 高频操作键盘可达，提升写作速度 |
| 成功消息自动消失 | 减少手动关闭操作 |
| 版本 Diff 可视化 | 直观看到 AI 生成 vs 人工编辑的差异 |
| 资产版本回滚 | 一键恢复到历史版本 |

### 2.3 质量提升

| 功能 | 价值 |
|------|------|
| 风格学习 v1 | 分析作者已写章节，学习句式/用词/节奏 |
| 风格应用到生成 | 新生成的章节自动匹配作者风格 |
| 质量 A/B 对比 | 同一章节用不同 prompt/模型生成，对比评分 |

### 2.4 可观测性

| 功能 | 价值 |
|------|------|
| SSE 实时事件推送 | 替代 2s 轮询，实时感知任务状态变化 |
| 任务进度条 | Web 端实时显示生成进度 |

## v3 中期规划（6-12 个月）

### 3.1 平台化

| 功能 | 价值 |
|------|------|
| 用户认证系统 | 多用户注册/登录，支持 SaaS 部署 |
| 云端存储 | S3 资产存储，云数据库持久化 |
| API 速率限制 | 防止滥用，保证服务质量 |
| 多租户隔离 | 不同工作室/作者数据完全隔离 |

### 3.2 智能生成

| 功能 | 价值 |
|------|------|
| 模型自动选择 | 根据任务复杂度自动选最优模型 |
| 世界观一致性 | 跨章节角色/设定一致性检查 |
| 伏笔追踪 | 自动标记和回收伏笔 |
| 多流水线并行 | 一个项目同时生成多个分支（番外/前传） |

### 3.3 发布集成

| 功能 | 价值 |
|------|------|
| 直接发布到平台 | 一键发布到起点/晋江等平台 |
| 定时发布 | 设定发布时间表 |
| 发布状态追踪 | 追踪已发布章节的阅读/评论数据 |

### 3.4 数据分析

| 功能 | 价值 |
|------|------|
| 章节质量趋势 | 可视化展示章节质量变化 |
| 读者反馈分析 | 收集平台评论，分析读者喜好 |
| Token 消耗分析 | 按任务/时间段分析 LLM 成本 |

## v4 远期愿景（12 个月+）

### 4.1 内容生态

- **角色卡生成与一致性维护**：自动维护角色画像，防止人设崩塌
- **时间线自动校验**：检测时间线矛盾
- **多语言翻译**：自动翻译成英文/日文等，支持海外发布
- **插画/封面生成**：AI 生成章节配图和书籍封面

### 4.2 团队协作

- **工作室管理**：团队项目管理，任务分配
- **审校工作流**：编辑审校 → 作者确认 → 发布的完整流程
- **版本分支管理**：类似 Git 的章节分支/合并

### 4.3 创作者工具集

- **写作习惯分析**：分析作者写作习惯，给出改进建议
- **章节节奏控制**：自动分析章节节奏（紧张/舒缓）
- **读者画像生成**：基于内容推断目标读者画像

## 设计决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| 前端架构 | 单 HTML 文件 | v1 无需构建工具，修改即生效 |
| 后端框架 | FastAPI | Python 生态，类型安全，异步原生 |
| 存储 | SQLite 优先 | 零配置部署，足够支撑个人/小团队 |
| LLM | 多 Provider | 不绑定单一供应商，支持本地回退 |
| 资产模型 | 统一 Asset 表 | 所有类型用同一模型，通过 asset_type 区分 |
| 并发控制 | 乐观锁 | 写作场景中并发冲突概率低 |
| 任务模型 | 状态机 | 明确的状态流转，可追溯可恢复 |
| UI 主题 | 暗色默认 | 长时间创作场景，护眼优先 |
